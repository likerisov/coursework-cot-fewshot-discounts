# Описание данных

Файл: `data/slow_moving.csv` (CSV, UTF-8).

| Поле | Тип | Значение |
|---|---|---|
| `product_id` | целое | Уникальный идентификатор строки товара |
| `category` | текст | Категория товара |
| `stock_quantity` | целое | Текущий остаток, шт. |
| `days_in_stock` | целое | Срок хранения, дней |
| `current_price` | число | Текущая розничная цена за единицу, руб. |
| `cost_price` | число | Закупочная стоимость единицы, руб. |
| `last_month_sales` | целое | Количество продаж за предыдущий месяц, шт. |

## Происхождение и ограничения
Набор является учебным и содержит восемь условных товарных записей. Даты, история цены, себестоимость полного цикла, расходы на логистику, хранение, комиссии и налоги отсутствуют. Нет фактических продаж после скидки. Поэтому данные подходят для демонстрации расчётов и сравнения ответов по внутренним ограничениям, но не для утверждений о реальном финансовом эффекте.
