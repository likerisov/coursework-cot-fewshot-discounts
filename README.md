# Курсовая работа

**Тема:** Сравнение подходов chain-of-thought и few-shot prompting для генерации советов и рекомендаций по скидкам на товары с низким оборотом.

## О проекте
В работе исследуется, какой метод общения с нейросетью (промптинг) лучше справляется с задачей анализа плохо продающихся товаров и выдачи рекомендаций по скидкам.

## Какие подходы сравниваются:
1. Zero-shot (без примеров)
2. Few-shot (с примерами)
3. Chain-of-Thought (пошаговые рассуждения)
4. Few-shot + Chain-of-Thought (смешанный)

## Структура проекта
* `data/` — тестовый датасет с товарами
* `prompts/` — тексты промптов для экспериментов
* `experiments/` — результаты прогонов и выводы
