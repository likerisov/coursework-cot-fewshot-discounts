# Эксперименты

- `results.md` — первоначальный ручной пилот: четыре ответа на один товар.
- `../results/manual_pilot_analysis.md` — арифметическая проверка пилота.
- `../results/planned_experiment_matrix.csv` — план экспериментов, ещё не выполненных.
- `../results/llm_runs.jsonl` — журнал новых API-запусков; создаётся локально.
- `../results/llm_evaluation.*` — сводки по фактически записанным ответам.

Провайдер и модель первоначального ручного пилота не зафиксированы. Для полного протокола см. `../docs/methodology.md`.
